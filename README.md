# مشروع نظام التشغيل OS Project

## نظرة عامة
مشروع نظام تشغيل (OS) بسيط مكتوب باستخدام لغات **C** و **Assembly**، يتضمن:
- جهاز تحميل (Bootloader)
- نواة النظام (Kernel)
- معالجات الأجهزة (Drivers)
- واجهة رسومية بسيطة (GUI)

## البنية الأساسية
```
├── boot/              # رمز التحميل الأولي
├── kernel/            # نواة النظام
│   ├── gui/          # وحدة الواجهة الرسومية
│   ├── gdt.c         # جدول الوصف العام
│   ├── idt.c         # جدول وصف المقاطعات
│   ├── paging.c      # نظام الترقيم
│   ├── vga.c         # معالج الشاشة
│   └── kernel.c      # النواة الرئيسية
├── drivers/           # معالجات الأجهزة
│   └── keyboard.c    # معالج لوحة المفاتيح
├── include/           # ملفات الرؤوس
│   ├── gui.h         # واجهة GUI
│   ├── vga.h         # واجهة VGA
│   ├── pit.h         # مؤقت النظام
│   └── mouse.h       # معالج الفأرة
├── Makefile          # نظام البناء
└── linker.ld         # ملف الربط
```

## المتطلبات
- `gcc` (مع دعم 32-bit)
- `as` (GNU Assembler)
- `ld` (GNU Linker)
- `make`

على Linux/Ubuntu:
```bash
sudo apt-get install gcc-multilib g++-multilib binutils
```

## البناء والتجميع

### بناء المشروع الكامل:
```bash
make
```

### مسح الملفات المرتجلة:
```bash
make clean
```

### إعادة البناء من الصفر:
```bash
make rebuild
```

## الملفات الرئيسية

### Boot Loader (boot/boot.s)
رمز التحميل الأولي الذي يقوم بـ:
- تهيئة المعالج
- تحضير بيئة النظام
- القفز إلى نواة النظام

### Kernel (kernel/kernel.c)
نواة النظام التي تدير:
- جدول وصف المقاطعات (IDT)
- جدول الوصف العام (GDT)
- نظام الترقيم (Paging)
- جدولة المهام

### Drivers
معالجات الأجهزة الأساسية:
- **keyboard.c** - معالج لوحة المفاتيح
- دعم معالجات إضافية يمكن إضافتها

### GUI Components (kernel/gui/)
مكونات الواجهة الرسومية:
- **desktop.c** - سطح المكتب الأساسي
